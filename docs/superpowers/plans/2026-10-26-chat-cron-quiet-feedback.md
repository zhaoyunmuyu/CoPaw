# 聊天定时任务反馈简化

用户要求移除聊天页新任务操作后的“操作与执行进度”自动弹窗，以及报告已展示时的“已读处理失败”提示。只改变这两处前端反馈，保留管理页手动查询进度、任务执行、结果刷新、已读请求、身份隔离与请求重试约束。保留其他真正操作失败的反馈。

1. 先补回归：聊天中执行请求已受理后不出现进度弹窗，列表仍刷新；报告已读失败仍展示报告、不弹警告，并继续遵守原已读接口调用规则。
2. 删除 Chat 对 ManagedProgressModal 的导入、状态消费和自动渲染；受理提示移除“请查看进度”的引导，保留简短受理反馈。
3. 报告 hook 的失败回调改为可选，FilePreviewModal 不再注册弹警告的回调；未读失败不伪造已读成功，关闭重开仍按原请求规则处理。
4. 执行相关测试、类型和格式检查，顺序自检；不得改动已有看板修复、后端接口和数据状态。GitNexus 因索引 WAL 问题无可靠图谱结果，已用源码核对调用点。
5. 不提交、不推送、不更新行内包。

- 请求幂等重试、工作区/Agent 隔离、报告已读归属与关闭取消、管理页手动进度弹窗共 9 项测试通过。

- TypeScript 类型检查、针对性 Prettier、pre-commit、`git diff --check` 通过。未整体格式化已有大型页面，避免修改无关代码。
